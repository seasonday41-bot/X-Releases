# X — Windows Releases

Official Windows downloads for **X — AI Worker**.

## Download

Use the **Releases** section of this repository to download the latest Windows installer:

`X-<version>-Setup-x64.exe`

This repository is for distribution only. The X application source code is maintained separately and is not published here.

## Install

1. Download the latest `.exe` installer from Releases.
2. Run the installer and choose the installation location.
3. Open **X** from the Start menu or desktop shortcut.
4. Follow the first-run setup shown by X.

> Windows may show a SmartScreen warning while builds are not code-signed.

## Platform

- Windows x64
